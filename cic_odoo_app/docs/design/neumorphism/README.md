# Concepto de rediseño neumórfico

Estos mockups sirven para validar la dirección visual antes de modificar la interfaz Flutter:

- [Inicio · modo claro](home-light.png)
- [Inicio · modo oscuro](home-dark.png)

## Dirección propuesta

- Neumorfismo suave y actual, con relieve moderado y superficies redondeadas.
- Azul marino y cian de CIC como acentos, manteniendo el flequillito como elemento de marca y carga.
- Jerarquía apoyada en color, tipografía y espaciado; nunca solo en sombras.
- Componentes compartidos para tarjetas, botones, campos, navegación y estados.

## Modo claro

- Fondo frío muy claro y superficies ligeramente elevadas.
- Sombras dobles discretas: una oscura y otra clara.
- Texto azul marino de alto contraste.

## Modo oscuro

- Fondo carbón, evitando negro puro.
- Superficies elevadas diferenciadas también por tono y borde.
- Texto casi blanco y acentos cian con contraste accesible.
- Brillos y sombras contenidos para evitar un aspecto de neón.
